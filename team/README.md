# Team

Everyone on the team adds one file here as their first pull request, named
after their GitHub username (for example `sam-codes.md`). Because each person
edits only their own file, these pull requests never clash with each other.

Put in your file:

- Your name
- What you'd like to work on (sensors, radio, data logging, ground station, ...)

See [docs/GETTING_STARTED.md](../docs/GETTING_STARTED.md), Step 9, for how to
commit, push and open the pull request.
